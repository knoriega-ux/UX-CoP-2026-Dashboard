# UX CoP 2026 Dashboard

UX CoP 2026 events and mentoring metrics, designed to help UX professionals see how our community is growing and where we’re investing our time.

## What’s in this repository

This repo contains structured data and a simple web dashboard (via GitHub Pages) for:

- **UX CoP events in 2026** (CoP meetings, Creative Sips, networking and mentoring sessions)
- **Mentoring cohorts from 2024–2026** (Cohorts I–III)

### Data file

- `uxcop_2024_2026_events_and_mentoring.csv`  
  - `Type` = `Event` or `Mentoring`  
  - Event rows include: date, month, session type, title, speakers, board host, attendees  
  - Mentoring rows include: year, cohort, total participants, mentors, mentees, peer-to-peer

You can open this file directly in Excel, Google Sheets, Tableau, or other tools to explore the data.
